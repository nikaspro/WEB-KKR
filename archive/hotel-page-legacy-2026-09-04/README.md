# Архивная страница Hotel — Luna

Старый автономный снимок страницы для отелей. Он сохранён только для истории и не участвует в сборке или публикации сайта.

Актуальная версия находится в `hotels/index.html` корневого проекта и локально открывается по адресу `http://127.0.0.1:5176/hotels/`.

## Локальный запуск

Требуется Node.js 22.

```bash
npm ci
npm run dev
```

После запуска страница доступна по адресу, который покажет Vite.

## Production-сборка

```bash
npm run build
npm run preview
```

В папке находятся только hotel-страница, используемые ею стили, скрипты, зависимости и ассеты.
