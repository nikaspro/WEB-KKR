# Блок «Все собрал»

Это самостоятельная версия блока анализа отеля с финальным состоянием «Все собрал» и пятью карточками результата

Архив не зависит от основного проекта, GSAP и ScrollTrigger лежат локально в папке `vendor`, поэтому пример можно открыть через любой статический сервер

## Как запустить

Из папки блока выполните:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080` и прокрутите страницу вниз

## Состав

- `index.html` — разметка инпута, статуса и пяти карточек
- `styles.css` — внешний вид плашки, анимированная обводка, световой текст и карточки
- `script.js` — GSAP-последовательность, связанная со скроллом
- `assets/` — четыре изображения, используемые карточками
- `vendor/` — локальные GSAP и ScrollTrigger

## Как устроена последовательность

Секция имеет большую высоту, а сцена внутри нее закреплена через `position: sticky`

ScrollTrigger связывает позицию скролла со временем одной GSAP-шкалы через `scrub: true`, поэтому при движении вниз анимация идет вперед, а при движении вверх корректно возвращается назад без накопления копий элементов

Статусы проходят пять этапов:

1. `Думаю`
2. `Открываю сайт`
3. `Изучаю страницы`
4. `Собираю главное`
5. `Все собрал`

Каждый этап одновременно меняет текст, размер плашки, небольшой угол наклона и скорость светового движения

## Как ускоряется обводка инпута

Обводка сделана двумя псевдоэлементами `::before` и `::after` с одинаковым `conic-gradient`

- `::before` рисует четкий световой контур
- `::after` повторяет его с blur и создает мягкое свечение
- CSS-свойство `--rim-spin` зарегистрировано через `@property`, поэтому угол можно плавно анимировать от `0deg` до `360deg`
- длительность полного оборота хранится в `--rim-duration`

В `script.js` у каждого статуса есть параметр `duration`

```js
{ text:'Думаю', duration:2.20 }
{ text:'Все собрал', duration:.78 }
```

При смене этапа GSAP записывает новое значение в CSS-переменную:

```js
timeline.set(shell, { '--rim-duration':`${step.duration}s` })
```

Чем меньше число, тем быстрее проходит полный оборот, поэтому контур постепенно ускоряется с `2.20s` до `.78s`

В финальном состоянии CSS дополнительно задает `animation-duration:.68s`, чтобы завершение ощущалось сильнее

## Как ускоряется свет по тексту

Сам текст прозрачен, а его видимая часть создается градиентом, обрезанным по форме букв через `background-clip:text`

Градиент шире текста и содержит яркую белую полосу в центре, а `@keyframes text-flow` перемещает его справа налево

Скорость хранится в `--text-flow-duration` и берется из того же параметра `duration`, что и обводка

```js
status.style.setProperty('--text-flow-duration', `${step.duration}s`)
```

Так текст и контур ускоряются синхронно и визуально ощущаются одной системой

На финальном статусе текст становится сплошным белым, а анимация градиента выключается, чтобы надпись «Все собрал» была максимально читаемой

## Как происходит смена цвета

Когда шкала доходит до времени финального статуса, функция `syncFinalState` добавляет секции класс `is-final`

Этот класс меняет сразу три слоя:

- фон внутри плашки становится насыщенно-синим `#1710dc`
- обводка получает более контрастный сине-голубой градиент с белыми бликами
- тени усиливаются и добавляют мягкое внешнее голубое свечение

Одновременно отдельная короткая GSAP-шкала запускает фоновую световую волну, а карточки вылетают из центра

При обратном скролле класс снимается, поэтому цвет и карточки возвращаются в исходное состояние без создания новых DOM-элементов

## Как сверстаны карточки

Все карточки лежат в контейнере нулевого размера, установленном точно в центре сцены

Каждая карточка начинается в центре и получает свой набор `x`, `y`, `rotation` и `scale` из массива `cardFlights`

Есть три формата:

- обычная вертикальная карточка
- широкая горизонтальная карточка с сеткой `52% / 48%`
- компактная карточка

Внутри используется простая структура: изображение плюс текстовый градиентный блок

Полупрозрачный фон, `backdrop-filter`, тонкая светлая граница и несколько теней создают эффект стекла

Для появления используется короткий `fromTo`: карточка начинает ближе к центру, затем быстро доезжает до конечной позиции через `power3.out`

```js
duration:.3
stagger:.018
ease:'power3.out'
```

Это дает ощущение одновременного выброса, но сохраняет едва заметную очередность

## Где менять параметры

- скорость текста и контура — массив `steps` в `script.js`
- общий размер финальной плашки — `scale` последнего элемента `steps`
- позиции карточек — функция `cardFlights`
- скорость появления карточек — `duration`, `stagger` и `ease` в блоке `fromTo(cards, ...)`
- цвета финала — селекторы `.collection.is-final` в `styles.css`

## Важная деталь стабильности

Карточки создаются один раз в HTML и только меняют transform и opacity внутри одной scrub-шкалы

Это предотвращает появление нескольких рамок и дубликатов при быстром скролле вниз и обратно
